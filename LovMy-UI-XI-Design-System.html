Notes pour le développeur

Ce fichier est une référence visuelle statique (HTML/CSS/JS vanilla) qui sert de spécification pixel-perfect pour reconstruire chaque composant en React/Next.js. La charte (tokens, gradients, ombres, animations) est déjà formalisée dans lovmy.css pour Tailwind v4 — importez-la telle quelle plutôt que de redéfinir les couleurs.

Installation

pnpm add @lovmy/ui clsx tailwind-merge

Importer les tokens une seule fois à la racine (ex. app/globals.css ou app/layout.tsx) :

import "@lovmy/ui/styles";

Polices Google Fonts à charger dans layout.tsx : Fraunces (serif display), Manrope (sans body), Space Grotesk (mono labels).

Exemple d'usage

import { AuroraPassion, ProfileCard, PassionButton, LikeButton } from "@lovmy/ui"; export default function Discover() { return ( <main className="min-h-screen"> <AuroraPassion /> <ProfileCard name="Aïcha" age={27} location="Abidjan" photo="/aicha.jpg" verified online tags={["Voyage", "Afrobeats", "Cuisine"]} /> <div className="mt-6 flex gap-4"> <LikeButton /> <PassionButton>Envoyer un message</PassionButton> </div> </main> ); }

lovmy.css — tokens Tailwind v4 (@theme complet) 
@import "tailwindcss";

/* Dark mode is the LovMy default. Toggle by adding `class="light"`
   on <html> (or use the `.dark` variant explicitly). */
@custom-variant dark (&:where(.dark, .dark *));
@custom-variant light (&:where(.light, .light *));

@theme {
  /* ---- Brand palette -------------------------------------- */
  --color-passion: #eb0603;   /* Rouge Passion — primary        */
  --color-ember: #f64135;     /* Braise — hover / highlight     */
  --color-velvet: #800001;    /* Velours — depth                */
  --color-nightred: #440004;  /* Rouge Nuit — deepest red       */
  --color-obsidian: #080714;  /* Obsidienne — canvas            */
  --color-steel: #303b63;     /* Acier Minuit — cool accent     */
  --color-blush: #e89ea1;     /* Rose Tendre — soft accent      */
  --color-ivory: #fbf7f6;     /* Ivoire — light surfaces        */

  /* ---- Surfaces & text (dark default) --------------------- */
  --color-ink: #0c0a16;
  --color-paper: #100b1c;
  --color-surface: #17111f;
  --color-line: rgb(232 158 161 / 0.16);
  --color-fg: #ede7ea;
  --color-fg-soft: #b8aeb8;
  --color-fg-faint: #7c7388;

  /* ---- Typography ----------------------------------------- */
  --font-serif: "Fraunces", Georgia, serif;         /* display */
  --font-sans: "Manrope", system-ui, sans-serif;    /* body    */
  --font-mono: "Space Grotesk", ui-monospace, monospace; /* labels */

  /* ---- Radii ---------------------------------------------- */
  --radius-lovmy: 1.25rem;
  --radius-lovmy-lg: 1.75rem;
  --radius-lovmy-pill: 999px;

  /* ---- Signature shadows ---------------------------------- */
  --shadow-passion: 0 18px 50px -12px rgb(235 6 3 / 0.45);
  --shadow-ember: 0 10px 34px -10px rgb(246 65 53 / 0.5);
  --shadow-velvet: 0 24px 70px -24px rgb(68 0 4 / 0.7);

  /* ---- Motion --------------------------------------------- */
  --ease-lovmy: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-heart: cubic-bezier(0.66, 0, 0.34, 1);

  /* ---- Signature gradients (as vars for reuse) ------------ */
  --gradient-passion: linear-gradient(135deg, #f64135 0%, #eb0603 45%, #800001 100%);
  --gradient-nuit: linear-gradient(160deg, #440004 0%, #080714 70%);
  --gradient-blush: linear-gradient(135deg, #e89ea1 0%, #eb0603 100%);

  /* ---- Keyframes ------------------------------------------ */
  --animate-heartbeat: heartbeat 1.4s var(--ease-heart) infinite;
  --animate-pulse-halo: pulse-halo 6s ease-in-out infinite;
  --animate-shimmer: shimmer 2.4s linear infinite;
  --animate-float: float 7s ease-in-out infinite;
  --animate-aurora: aurora 18s ease-in-out infinite;
  --animate-rise: rise 0.7s var(--ease-lovmy) both;
}
